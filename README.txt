🏏 SupeRR Selector – Pressure Performance Dashboard

A responsive cricket analytics dashboard developed for SupeRR Selector Season 2 – Round 1. This project focuses on identifying batters and bowlers who perform consistently under high-pressure situations in T20 cricket.

The dashboard features a Rajasthan Royals-inspired design using pink, royal blue, and white, providing a clean and interactive experience.

🚀 Features

Top 10 Batters: Displays the best-performing batters under pressure.

Top 10 Bowlers: Highlights bowlers with strong pressure performance.

Search Functionality: Easily search for players in the rankings.

Performance Statistics: Displays pressure runs, strike rates, wickets, economy and other key metrics.

Methodology: Explains the pressure conditions and ranking approach.

Responsive Design: Supports desktop and mobile screens.

Interactive Interface: Simple navigation between dashboard sections.

📊 Analysis Overview

The dashboard analyses player performances in IPL and T20 International matches from 2022–2026 using the supplied dataset.

Pressure Situation Definition

A delivery is considered a pressure delivery when:

The match is in the second innings.

At least 12 overs have been completed.

The required run rate is 9 or more runs per over, OR the chasing team has four or fewer wickets remaining.

Player Evaluation

Batters:

Pressure strike rate

Boundary frequency

Runs per dismissal

Comparison with normal performance

Bowlers:

Pressure economy rate

Wickets per 24 legal balls

Dot-ball percentage

Comparison with normal performance

💻 How to Run

Clone or download this repository.

Open the project folder.

Open index.html in any modern web browser.

Explore the batter rankings, bowler rankings and methodology sections.

🌐 Deployment

This dashboard can be hosted using GitHub Pages.

Upload the project files to a public GitHub repository.

Navigate to Settings → Pages.

Select Deploy from a branch.

Choose the main branch and / (root) folder.

Save the settings.

Access the published dashboard using the generated GitHub Pages URL.

🎯 Project Objective

The objective is to use data-driven performance analysis to identify reliable T20 players who can handle high-pressure match situations and support informed player selection decisions.

⚠️ Disclaimer

The rankings are based on the supplied dataset and the defined pressure-performance methodology. They represent analytical results from the available data and should not be considered guarantees of future performance or official Rajasthan Royals selections.
