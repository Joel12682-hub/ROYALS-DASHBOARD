RR Pressure Performance Dashboard

Open index.html in a browser to use the dashboard.
It is a self-contained website file with interactive tabs and searchable player tables.

To publish for a public URL:
1. Create a public GitHub repository.
2. Upload index.html to the repository root.
3. Open Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Wait for the public GitHub Pages URL and test it before using it in Unstop.

Check all player names and statistics against the official competition dropdown/data before submitting.
